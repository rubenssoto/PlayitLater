PlayItLater Privacy Policy

Effective date: March 28, 2026

1. Overview

PlayItLater is a Chrome extension that helps users save and organize YouTube videos to watch later. We designed PlayItLater with a privacy-first approach: data is processed locally in the user’s browser.

2. Data We Process

PlayItLater may process and store the following data locally:

  • YouTube video metadata (for example: title, channel name, video URL, thumbnail URL, and duration when available).
  • Watch status and playback progress (Unwatched, In progress, Watched, and progress percentage).
  • User-created categories, tags, and interface preferences (theme, language, and related settings).

3. Where Data Is Stored

PlayItLater stores extension data locally in the browser using chrome.storage.local. PlayItLater 1.0 does not use a remote backend for syncing user data.

4. Network Access

To provide its core functionality, PlayItLater runs only on YouTube hosts declared in the extension manifest (https://www.youtube.com/* and https://youtu.be/*). The browser may also request media/metadata from YouTube-owned domains such as i.ytimg.com to display thumbnails.

5. Data Sharing and Selling

We do not sell personal data. We do not share user data with data brokers or advertising platforms. We do not use user data for creditworthiness or lending purposes.

6. Purpose Limitation

PlayItLater uses data only to provide and improve its single purpose: saving and organizing YouTube videos for later viewing.

7. Permissions Rationale

  • storage: Save library data, categories, tags, progress, and preferences locally.
  • activeTab: Read metadata from the currently active tab only after explicit user action (popup capture or shortcut).
  • Host permissions: Limit content-script execution to supported YouTube pages for capture and progress tracking.

8. Remote Code

PlayItLater does not use remotely hosted executable code. Executable code is packaged in the Chrome Web Store item.

9. User Controls

  • Export data to JSON/CSV.
  • Import JSON backups.
  • Delete library items.
  • Uninstall the extension at any time.

10. Children’s Privacy

PlayItLater is not designed specifically for children.

11. Changes to This Policy

We may update this policy when the product changes. We will update the effective date accordingly.
